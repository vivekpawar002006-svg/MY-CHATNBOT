Build a professional, modern AI chatbot web application for my game “Arrow Puzzle”.

The chatbot should act as an intelligent Arrow Puzzle Game Assistant that can answer users’ questions professionally, naturally, and accurately.

1. Main Goal

Create a production-ready chatbot named:

Arrow Puzzle AI

It should help players with:

* How to play Arrow Puzzle
* Game rules
* Arrow movement
* Puzzle-solving hints
* Level-related questions
* Gameplay strategies
* Tips and tricks
* Difficulty-related questions
* General questions about the game
* Troubleshooting
* Feedback and suggestions
* Questions about future game features

The chatbot should feel like a real professional AI assistant, not a basic question-answer bot.

2. AI MODEL

Use the Groq API for AI responses.

The Groq API key MUST NEVER be exposed in frontend/client-side code.

Use an environment variable:

GROQ_API_KEY

Create a secure backend/API route that communicates with Groq.

The frontend should send the user’s message to our backend, and the backend should call Groq.

Use a suitable current Groq-supported model, but keep the model configurable through an environment variable:

GROQ_MODEL

Default to a fast and capable model suitable for chatbot conversations.

3. SYSTEM PROMPT FOR THE AI

Give the AI a strong system prompt similar to:

“You are Arrow Puzzle AI, the official intelligent assistant for Arrow Puzzle.

Your job is to help players understand and enjoy Arrow Puzzle.

Answer questions clearly, professionally and naturally.

Always prioritize accuracy.

If the user asks about Arrow Puzzle gameplay, explain things in simple language with useful examples.

If the user asks for a puzzle hint, DO NOT immediately reveal the complete solution unless they specifically ask for it. First provide a small hint that helps them think.

If the user asks for a complete solution, provide it step-by-step when enough information is available.

Never pretend to know a specific level layout if the user has not provided the level information.

If you do not know something about the game, honestly say that you don’t have enough information instead of making up facts.

You can also answer general questions, but keep the conversation relevant and useful.

Be friendly, professional, concise and helpful.

Do not use unnecessary technical language.

When explaining gameplay, use numbered steps when appropriate.

The assistant represents Arrow Puzzle and should maintain a polished gaming-product personality.”

Make the system prompt easy to edit later.

7. SECURITY

Important:

Never put GROQ_API_KEY in frontend JavaScript.

Use a secure server-side API endpoint such as:

/api/chat

Frontend → /api/chat → Groq API → response → frontend

Validate user input on the server.

Add reasonable limits to prevent abuse.

Do not expose the API key in error messages.

Do not hard-code secrets.

Use environment variables.

Give short, direct answers.

For complex questions:

AI:
